# packages/&lt;名字&gt; · 一句话说明它提供什么能力

> **本文件是模板。** 新增共用库：
> ```bash
> cp -r packages/_template packages/<名字>
> ```

## 什么东西该进 packages/

**被两个以上 service 或 workflow 用到的东西**，才放这里。

只被一个地方用的，留在那个地方——过早抽公共库会制造无谓的耦合，
而且改一处要验 N 处。

## 提供什么

导出的函数/类，一行一个。这是它的公开契约，改了就要检查所有调用方。

## 明确不做

- **不持有状态**：库不写心跳、不写 `-state.json`。状态是调用方的事。
- **不决定日志去向**：库只返回结果或抛异常，由调用方决定怎么记。

## 判据

1. 例：**被 ≥2 个调用方使用**，只剩 1 个调用方时应当内联回去并删除本包。
2. 例：**公开契约变更必须同一提交内更新全部调用方**，不留过渡期。
