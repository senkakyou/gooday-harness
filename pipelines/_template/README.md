## 依赖

- 库：`packages/tts` 等
- 外部服务：edge-tts / 某 API
- **产物写哪**：`/srv/gooday/media/<名字>/`（G01，绝不写进本目录或版本库）

## 判据

必须可证伪。产线最容易变成"跑着但没人看"，判据要能判死刑。

1. 例：**每天出片 ≥20 集，连续 7 天失败率 <5%**。
2. 例：**产出 90 天内有人打开 ≥1 次**，否则下架这条线。
3. 例：**跑满 600 集即关停**，不无限续。

> 上一版有条产线停摆两个月无人发现——因为没人说得清它算不算还活着。

## 停摆判定

**这条必须写。** 说明什么现象算这条线死了、谁会发现、怎么发现。

- 判活看**产物 mtime**，不看日志——日志会骗人（权限警告顶掉真因，只剩 rc=1）。
- 例：`/srv/gooday/media/<名字>/` 最新文件超 48 小时未更新 = 停摆。
