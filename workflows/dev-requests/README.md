# dev-requests —— 处理开发需求工单

轮询库里的新需求工单，交给 Claude 判断并推进。没有新需求时输出「暂无新需求」。

## 判据
```bash
python3 workflows/dev-requests/run.py     # 退出码 0；无新需求时也算成功
```

## 频率是【反推的，需要核对】
root crontab 当前身份读不到，`5,25,45 * * * *` 是按旧日志两次写入时刻
（:45 与 :05，相隔 20 分钟）推出来的。真实值请用 `sudo crontab -l` 核对后修正本文件。

## 明确不做
不自己发消息给人 —— 需求的回复走工单系统，避免同一件事两个出口。
