# workflows/disk-cleanup · 磁盘回收

每天 19:00 一轮，只清**可再生**的垃圾。

## 铁律：每一项都要能回答「删了怎么变回来」

答不上来的就不该在清理列表里。现有六项都注明了再生方式（见 `run.py` 的 `ACTIONS`）。

**绝不碰**：docker 卷（含线上数据库）、运行中的容器与镜像、备份、源码、
浏览器运行时。这些删了要么丢数据，要么下次跑起来才发现少东西。

## 比旧脚本多的两样

1. **清理量留痕**——每次回收了多少写进 Event。
   连续几次回收量接近 0，说明它已经没在起作用，该查是不是清理项失效了。
2. **低水位告警**——清完仍低于阈值报 P1。
   「清理跑了」不等于「空间够了」：可再生的垃圾清完之后，
   占地的就是真东西，需要人来判断删什么。

## 判据

1. **一项失败不中断整轮**——某个清理命令挂了，其余照常执行并留痕。
2. **清理后可用空间 ≥ `low_water_gb`**，否则报 P1 并以非零退出。
3. 每轮必须留下 before/after 两个 Event——没有量化就无法判断它是否还在起作用。

## 停摆判定

`/var/log/gooday-harness/disk-cleanup.log` 超 48 小时无新内容 = 停摆。
