# 003 · 工具讲解片标准

> 状态：已生效（2026-09-08 起）· 执行者：`workflows/tool-video/`
> 这份标准**是可执行的**：`writer.py` 的验收函数逐条实现了下面的硬指标，
> 不达标就整篇拒收、这一轮不出片。标准改了，那边的常量要跟着改，否则就是一句空话。

## 一、片子是什么形态

**两个人对讲的一堂课，不是产品介绍。**

| | |
|---|---|
| 讲解（teacher） | **男声**（云健）。懂这个工具，也懂它背后那套东西。讲原理、讲取舍、讲坑 |
| 提问（asker） | **女声**（晓晓）。替观众提问，问的必须是真问题——用户会卡住、会误解、会追问的地方 |

画面分两块，分工固定，观众不用重新找视线落点：

```
┌──────────────────────────────────┐
│  板块区：要点 / 三卡 / 步骤 /      │   ← 随讲解逐条点亮，不一次全亮
│          对照 / 结论              │
├──────────────────────────────────┤
│ 👨‍🏫 讲解 │  字幕（当前这句）  │ 🙋‍♀️ 提问 │   ← 谁在说谁高亮
└──────────────────────────────────┘
```

配背景音乐：**自己合成的和弦垫**（不用外来音乐，版权说不清），音量压在人声下两档，
并且**有人说话时自动让路**（sidechain 闪避）。不做闪避的话，观众不会说"音乐大了"，
只会觉得"这人讲得含混"，然后关掉。

## 二、硬指标（`writer.py` 逐条校验）

| 项 | 标准 | 为什么 |
|---|---|---|
| 轮次 | ≥ 14 轮 | 少于这个数不可能讲透 |
| 提问 | ≥ 4 轮，且**不能全堆在前半段** | 少了是单口相声；堆在开头是"开场白式提问" |
| 全片字数 | ≥ 900 字 | **时长不限，但"讲清楚"有下限** |
| 展开轮 | ≥ 6 轮是 45 字以上的展开 | 通篇一问一短答 = 没讲 |
| 单轮字数 | 8 ~ 110 字 | 长了字幕排不下、听着也累，让它拆成多轮 |
| 深度 | 全片至少出现一次「为什么/取舍/代价/坑/误区/适合/前提/限制/怎么选」 | 挡住"功能罗列" |
| 板块 | 至少一块 `compare` 或 `quote` | 有取舍或有结论，才叫讲解 |
| 开场收尾 | 首轮 teacher + cover 板；末轮 teacher 收一句结论 | |

**时长不设上限。** 讲清楚为止——这是大海定的口径。上限只留一个跑飞保护
（成片 > 20 分钟判为异常，不上架）。

## 三、不许越过的线

1. **只能用工具自己的素材**（名称、描述、说明文档、在线页正文）。
   素材没提的功能、数字、平台名，一个字都不许加。
   - 但**可以基于素材做专业解释**：素材说"用 yt-dlp"，可以解释 yt-dlp 是什么、
     这类工具为什么要频繁更新——这是讲解，不是编造。
2. **数字必须能对上**。旁白里出现的 `3.3.5a`、`1080p`、`7890` 这类 token，
   必须在素材里出现过。模型最容易编的就是数字，而数字恰恰最像真的。
3. **不写夸张词**：最好 / 第一 / 唯一 / 保证 / 无限 / 永久免费 / 全网最 / 百分百 …
4. **素材里写明的限制，必须专门讲**。
   例：「视频拉取」的网页端只是演示，真下载要装到本机——
   这种话是用户最需要提前知道的，替工具吹成"在线可用"就是骗点击。
5. **模型不产 HTML**。它只填结构化字段，版式在代码里。
   既是排版一致性，也是因为把不可信文本插进页面是另一回事。

## 四、判定：什么叫这条线还活着

- **每周至少出一条**（有待处理工具时）。
- 成片能被 `ffprobe` 读出音视频两条流，时长 ≥ 60 秒。
- 上架后**回查线上**：详情接口认它、静态直链 206 支持 Range。回查不过就整体撤回。
- 画面里的中文不是方块（文字必须在浏览器里排版，不能交给 ffmpeg drawtext）。
- **90 天内播放数仍为 0 的片子，说明这条线在自嗨** —— 该停或该改形态。

## 五、这份标准是怎么来的

2026-09-08 第一版是"介绍片"：五幕、一个旁白、六十秒讲功能。
大海看完的原话是「我要专业有深度的讲解，不要只是介绍，内容要展开讨论，
有老师讲还有人提问」「一男一女的」「时间不限制，讲清楚为止」「再加上背景音乐」。

第一版那三条（小飞机 / 魔兽搭建手册 / 视频拉取）按本标准重做。
旧稿留档在 `workflows/tool-video/samples.py`，作为"什么叫只是介绍"的反面样板。
