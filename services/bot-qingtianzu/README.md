# services/bot-qingtianzu · 擎天柱（AI 项目经理）

分析工单、生成项目方案、汇报进度。主循环走 `packages/botkit/runner.py`。

## 职责与边界

| 做 | 不做 |
|---|---|
| 方案、拆任务、报价建议、工期估算 | **不接触客户**（对外只有一个窗口） |
| 跟踪进度、向站长汇报 | **不做开发**——实现归威震天 |
| | 不改工单状态，只产出分析结果 |

## 从旧版改了什么

- prompt 从 .py 里提出来 → `prompt.md`
- **补上注入防御条款**（旧版 grep 命中 0 处）
- 加了项目经理专属铁则：报价给区间不给单点数字（单点会被当成承诺）、
  工期估算必须说清假设
- **系统先查好工单事实注入 prompt**，不让模型自己查库——
  沙箱里命令可能不可用，它会跳过查询靠记忆编造

## 判据

1. 只读模式下零发送零写入。*实测：启动即只读。*
2. 工单事实查询正常。*实测：待分析/进行中/已交付/失败 四项 ＋ 最近 5 单摘要。*
3. 出口白名单只允许站长与调度中心，**客户发不到**。
