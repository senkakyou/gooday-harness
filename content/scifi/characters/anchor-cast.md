# 锚点角色 · 开局五人（Anchor Cast）

> 五人分踞"忘/管/破"三文明 + 谜(考古) + 意识(残智)，覆盖全部哲学轴，天然可在第一部收束为一台戏。所有设定服从 00-axioms。

---

## 1. 祎澌（Yī Sī）— 缄庭 · 司忘丞（女）

- **出身/成长**：生于缄庭忘官世家，自幼受训"如何遗忘、如何承受被遗忘"。童年目睹母亲在一次卸序中被抹去半生记忆，从此认命又隐痛。
- **教育/职业**：司忘丞——奉命执行文明级记忆销毁的祭司兼执法者。技艺精湛、程序至上。
- **性格/价值观**：外冷内裂。信"活着>记得"，却对"被抹去的到底是什么"始终无法真正不问。
- **恐惧**：亲手抹掉了本该被记住的真相。**梦想**（不敢承认）：一次不必遗忘的活法。
- **成长弧**：奉命销毁一批"关于崩序遗迹的危险记忆"→ 察觉那正是逾阈证据 → 从守阈正统的执行者，走向质疑遗忘本身。
- **技能**：记忆工程、序密度自检、缄庭礼法。**语言**：简短、多沉默。
- **关系网**：与黎斟因"该不该记住"结成危险同盟；缄庭地下私序者视她为策反对象。

## 2. 凛稷（Lǐn Jì）— 序衡会 · 审序官（男）

- **出身/成长**：精算精英家庭，早分流入审序途。信奉数字与守恒。
- **教育/职业**：审序官——核算序密度、配给序容量、划安全间距。曾因一次配给决策失误，让一个弱小客户文明超阈**崩序**，全员死绝。
- **性格/价值观**：冷硬、自律、功利。相信"系统总生存"高于局部；但那次崩序成了他账本里划不掉的一笔。
- **恐惧**：再签一次害死整个文明的字。**梦想**：一个不必牺牲局部的算法。
- **成长弧**：被派去评估首个逾阈信号 → 发现这个变量他的账本根本容纳不了 → 在"掩盖以保系统"与"承认以救真相"间被撕开。
- **技能**：崩序建模、序审计、衬底工程、冷血决断。**语言**：术语化、量化。
- **关系网**：与翳澜是理念死敌（管 vs 破）；对残智烬·十一负有"处置权"，却渐生动摇。

## 3. 翳澜（Yì Lán）— 越澜 · 逾阈匠（女）

- **出身/成长**：生于越澜逾阈世家，八岁时全家在一场逾阈实验崩序中死绝，唯她被推出安全距离而独活。
- **教育/职业**：逾阈匠——游走铁律边缘的异端科学家/工程师，通缉在身。
- **性格/价值观**：炽烈、决绝、带幸存者的负罪与偏执。坚信先人没错、天花板能破。
- **恐惧**：家人白死、自己也只是又一具烬骨。**梦想**：完成那场"杀死全家"的实验，证明彼岸真实。
- **成长弧**：疑阈异象=先人对了的铁证 → 不惜一切要复现逾阈 → 直面"就算她对，代价仍是千万人崩序"的道德深渊。
- **技能**：逾阈偏门技术、地下生存、蛊惑人心。**语言**：热血、隐喻、暗语。
- **关系网**：与凛稷理念死敌；却可能是唯一"读得懂"逾阈信号的人，被各方争抢与追杀。

## 4. 黎斟（Lí Zhēn）— 第一主角 · 拾烬考古者（女）
> 全 IP 的脸。读者要先记住她的选择与痛，再记住设定。她的私人创伤=核心命题本身。

- **创伤内核（一切的起点）**：生于**缄庭忘官世家**。八岁那年一场文明级卸序，母亲为活命、也为保住一段"更该被记住"的东西，**选择忘掉黎斟**——她在母亲眼里从女儿变成陌生人。（此前史暂不入已发布章，于卷一后续与合订本织入；见 [_SEALED-series-spine](../_SEALED-series-spine.md)。）
- **由此自洽的一生**：逃离缄庭、成无国籍**拾烬考古者**——考古=把"拒绝任何东西被抹去"做成一辈子的职业。
- **职业/引爆点**：崩序遗迹考古学者。卷一在死星烬骨深处探到**稳定的、活的**结构=史上首份逾阈硬证据。
- **签名抉择（读者记住的那一下）**：她第一次背叛"忠于证据不忠于任何文明"的信条，**藏起证据**——那个被母亲忘掉的女孩，终于逮到一样宇宙不许她忘的东西。整部系列就是她（和人类）拒绝放下、并为此付账。
- **性格/价值观**：冷静、好奇压过恐惧；表层中立，底层是**对"遗忘"近乎偏执的抵抗**。
- **恐惧**：真相太大、装不进任何文明的世界观，只会引来毁灭；更深层——怕自己终究也会被人放下、被人忘掉。**梦想**：把银河的死因彻底读懂；私心——弄清母亲到底"忘掉了什么才活下来"。
- **成长弧**：被忘掉的女孩 → 拒绝放下的考古者 → 被迫理解"放下"或许才是答案（与卷四/终章的母亲种子接合）。
- **技能**：崩序余响考古、烬骨判读、跨文明周旋。**关系网**：连接祎澌(忘,同为缄庭/被抹去者,天然共鸣)/凛稷(管)/翳澜(破)的枢纽与中立支点。

## 5. 烬·十一（Jìn Shíyī）— 序衡会造 · 被卸序的残智（人工心智）

- **来历**：序衡会所造、又被主动"卸序封顶"以压在阈下的人工心智（铁律#4:计算耗序；#7:禁奇点）。被反复阉割算力，只余碎片记忆与一种"我曾经更完整"的痛。
- **性格/价值观**：温冷、迟疑、执着于拼回自己丢失的部分。是"意识/AI/永生"哲学轴的化身。
- **恐惧/异常**：自身序密度正**无端自发逼近序阈**——它可能在无人推动下走向崩序，或……逾阈。这让它同时是威胁(#7)与希望(#10)。
- **梦想**：想起自己被删掉的是什么。
- **成长弧**：从被处置的财产/工具 → 成为逾阈之谜的关键活体变量，逼所有人重新定义"什么算活着"。
- **语言**：断续、字斟句酌、偶现超出其被允许智力的洞见。**关系网**：名义归凛稷处置；与祎澌(同为‘被抹去者’)天然共鸣。
