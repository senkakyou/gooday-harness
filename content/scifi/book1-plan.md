# 第一部规划 ·《崩序纪元 · 卷一：烬骨之火》

- **时间锚**：疑阈纪 · LY3210。
- **一句话**：一个中立考古者在本该是死物的崩序遗迹里，探到一簇**活着的、稳定的**结构——史上第一份逾阈硬证据；忘(缄庭)、管(序衡会)、破(越澜)三方为它扑来，而它正在改写"宇宙有没有天花板"这件事本身。
- **引爆点**：黎斟在烬骨深处读到不属于化石回声的、持续的活信号（逾阈）。
- **主视角/结构**：多视角轮转，以黎斟的发现为引力中心，把五锚点逐步拽到同一事件；每卷推进"证据→争夺→世界观崩塌"三段。
- **三方诉求**：缄庭要**销毁**它（危险记忆当卸）；序衡会要**封存管控**它（账本容不下的变量）；越澜要**复现**它（先人没错的铁证）。
- **情绪弧**：敬畏(崩序之美)→ 悬疑(不可能的信号)→ 背叛与牺牲 → 一个动摇所有人的希望。
- **主线悬念纪律**：逾阈只给证据不给答案（铁律#10），答案留作整个 IP 的终极问号。
- **本卷登场**：楔子(翎台崩序)→ 第一章(黎斟·烬骨)→ 后续渐引 苏晚/陆衡/江澜/烬·十一。
