## 七环怎么落到这条闭环上
| 环 | 这条闭环里是什么 |
|----|------------------|
| Run | |
| Evaluate | 打分口径。**必须真的会判 fail** |
| Learn | 失败怎么归类成结构化经验 |
| Improve | 每类经验对应什么候选 |
| Experiment | **隔离在哪里跑**——绝不能拿真身做实验 |
| Gate | 至少三条：超过基线、无回归、不能靠"藏问题"提分 |
| Promote/Rollback | checkpoint 存什么、怎么复原 |
