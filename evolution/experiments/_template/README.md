## 要验证的改动

改什么。一句话。改 prompt？改阈值？改流程？换模型？

## 关联的 Decision

`docs/decisions/NNN-xxx.md` —— **没有 Decision 的实验不许跑**。
改动的理由必须先写下来，否则实验结果无从解释。

## 验证方式

三选一，**优先影子模式**：

| 方式 | 怎么做 | 什么时候用 |
|---|---|---|
| **影子** | 新逻辑只算不做，与现状比对一致率 | 改决策逻辑（dispatcher 就是这么上线的） |
| **灰度** | 只对 N% 的对象生效 | 改动有副作用、无法只算不做 |
| **前后对比** | 同一评价器，改动前后打分对比 | 改 prompt、改模型 |

## 通过判据

**必须先写死，不许跑完再定。** 事后定判据 = 自己骗自己。

- 例：**影子决策与现状一致率 100%**，积累 ≥20 个真实样本
- 例：**评价器均分提升 ≥0.1，且 fail 数不增加**
- 例：**连续 7 天无新增事故**
